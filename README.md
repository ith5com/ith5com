### 🧱 我怎么做系统

- **权限由业务服务控制。** 身份、配额、扣点与越权检查收敛在 Go 侧，Python 在受控的租户上下文中执行 AI 任务。
- **用代码约束模型输出。** 复习题依据必须在正文逐字定位。知识图谱由代码生成候选、模型判断关系、并查集完成合并。
- **先评测，再改提示词。** 规则与模型裁判结合，支持基于产物快照重评。提示词从 v1 到 v6 均保留评测数据。
- **公共机制沉淀到运行时。** 统一处理记账、超时、熔断与任务回收，通过工具、Schema 和业务校验回调支持不同场景。
