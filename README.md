### 🧱 我怎么做系统

- **权限收敛到业务服务。** Go 统一处理身份、配额、扣点与越权检查，Python 接收受控的租户上下文和正文，AI 调用遵循服务端权限约束。
- **用代码约束模型输出。** 复习题依据必须在正文逐字定位，定位不到则作废。知识图谱由代码按句共现生成候选、模型选择关系、并查集完成合并。
- **先评测，再改提示词。** 结合规则与模型裁判评估只读产物快照，调整评分标准后可重评历史产物，省去重新生成的费用。提示词从 v1 到 v6 均有评测数据记录。
- **公共机制沉淀到运行时。** 工具循环、结构化输出、记账、超时、三态熔断、僵尸任务回收与幂等回调由 Runtime 承担，业务 Agent 通过提示词、工具、Schema 与校验回调接入。
